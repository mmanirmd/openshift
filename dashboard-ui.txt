Create a modern enterprise web dashboard called "NPE Platform Portal" for Kubernetes and Red Hat OpenShift platform engineers.

PURPOSE
This is an internal multi-cluster operations portal used by a Platform Engineering/SRE team to monitor and operate Kubernetes and OpenShift clusters.

The portal will eventually manage approximately 6 OpenShift clusters. It should provide a consolidated operational view so engineers do not need to constantly switch between individual OpenShift consoles or run kubectl/oc commands.

DESIGN STYLE
Create a professional enterprise operations dashboard.

Use:
- React + TypeScript
- Clean modern enterprise UI
- Dark navy left navigation
- White/light-gray main content area
- Compact but highly readable layout
- Subtle borders and shadows
- Rounded cards, but avoid excessive rounding
- Strong information hierarchy
- Status badges for Healthy, Warning, Critical, and Unavailable
- Green only for healthy/success
- Amber for warnings
- Red for critical/failure
- Gray for unavailable/unknown
- Responsive layout
- Desktop-first design for engineers using large monitors

Avoid:
- Consumer-style dashboard design
- Excessive gradients
- Huge cards
- Decorative charts without operational value
- Excessive animations
- Making everything look clickable when it is not

MULTI-CLUSTER BEHAVIOR

The portal must treat every cluster independently.

If one cluster API is unreachable, the entire dashboard must NOT hang.

Example:

npe03   Unavailable

SECURITY

This is an enterprise internal platform.

Never expose:
- kubeconfig
- Kubernetes tokens
- OpenShift tokens
- service-account credentials
- API credentials

The browser communicates only with the backend API.

UX PRIORITY

Optimize the dashboard for experienced Kubernetes/OpenShift platform engineers.

The most important question the Overview page should answer within approximately 5 seconds is:

"What needs my attention across my clusters?"

The second question should be:

"Which cluster/resource should I investigate?"

The third should be:

"What operational action is currently running or should I run next?"

Prioritize operational clarity, fast troubleshooting, fleet visibility, and safe navigation over decorative visual design.
